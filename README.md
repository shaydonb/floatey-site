# floatey-site

Public pages for the floatey app, served by GitHub Pages from the `gh-pages` branch.

- `privacy/index.md` is the current policy. Its URL, https://shaydonb.github.io/floatey-site/privacy/, is the one given to App Store Connect and should never change.
- `privacy/<version>/index.md` keeps each version's policy as published. When the policy changes for a new app version, copy the new text into a new version folder and into `privacy/index.md`, and add the version to the list at the top of `privacy/index.md`.
- The in-app copy is `floatey/Docs/05-privacy.md` in the floatey repo; keep the two in sync.
